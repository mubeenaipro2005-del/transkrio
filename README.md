# Bolo Likho — مفت اردو آڈیو/ویڈیو ٹرانسکرپشن (PWA)

Whisper (MIT) اور Transformers.js (Apache-2.0) آپ کے براؤزر میں چلتے ہیں۔ کوئی سرور، API key یا ادائیگی نہیں۔

## GitHub Pages پر چلانا (موبائل سے)
1. ZIP کو Files ایپ میں Extract کریں۔
2. github.com پر مفت اکاؤنٹ بنائیں، New repository، Public، Create۔
3. Add file ← Upload files ← Extract شدہ **سب** فائلیں (tests فولڈر سمیت یا اس کے بغیر) چنیں ← Commit changes۔
4. Settings ← Pages ← Deploy from a branch ← Branch: main، فولڈر: / (root) ← Save۔
5. 1 سے 2 منٹ بعد لنک آئے گا۔ Chrome میں کھولیں اور مینو سے Add to Home screen کریں۔

## استعمال
فائل منتخب کریں (یا ریکارڈ کریں) — کام **خود بخود شروع** ہو جاتا ہے۔ زبان/ماڈل پہلے سے چن لیں؛ سیٹنگز یاد رہتی ہیں۔
- ماڈل کا ڈاؤن لوڈ (پہلی بار) اور فائل کی ڈی کوڈنگ ساتھ ساتھ ہوتے ہیں۔
- لمبی فائل 5 منٹ کے حصوں میں بٹ کر (خاموشی کے مقام پر کٹ کر) پروسیس ہوتی ہے؛ ہر حصہ مکمل ہوتے ہی متن اسکرین پر آتا جاتا ہے۔
- عارضی خرابی پر ہر حصہ 2 بار خودکار دوبارہ آزمایا جاتا ہے۔ پھر بھی ناکام ہو، یا آپ "منسوخ" دبائیں، تو اب تک کا متن محفوظ رہتا ہے اور **جاری رکھیں** بٹن بقیہ حصے سے کام آگے بڑھاتا ہے (فائل دوبارہ دینا نہیں پڑتا؛ ٹیب بند نہ کریں)۔
- میموری کم پڑے تو چھوٹا ماڈل چن کر "جاری رکھیں" دبائیں۔
- نتیجہ: کاپی، TXT، SRT، VTT، DOCX، PDF (Print ← Save as PDF)۔
- پروسیسنگ کے دوران اسکرین سلیپ نہیں ہوتی (Wake Lock)، ورنہ فون کام روک دیتا ہے۔

## حدود (ایمانداری سے)
- درستگی ماڈل پر منحصر ہے: Tiny/Base کی اردو کمزور ہے؛ Small بہتر مگر سست اور بھاری (تقریباً 250 MB ڈاؤن لوڈ)۔ 100 فیصد درست نتیجے کی ضمانت ممکن نہیں؛ شور والی آڈیو میں غلطیاں بڑھتی ہیں۔ ایڈیٹر میں درست کریں۔
- پوری فائل کی آڈیو RAM میں ڈی کوڈ ہوتی ہے۔ 1.5 GB سے بڑی فائل مسترد ہوتی ہے؛ بہت لمبی (کئی گھنٹے) فائل پر فون کی میموری ختم ہو سکتی ہے۔ ایسی صورت میں ویڈیو سے آڈیو الگ کرکے دیں۔
- ویڈیو کا کھلنا براؤزر کے کوڈیک پر منحصر ہے۔ فارمیٹ نہ کھلے تو واضح پیغام آتا ہے۔
- رفتار فون کے CPU پر منحصر ہے (ماڈل WASM پر چلتا ہے)۔ GitHub Pages ملٹی تھریڈنگ کے ہیڈرز نہیں دیتا، اس لیے سنگل تھریڈ چلتا ہے۔ تیز تر نتیجہ سرور/GPU کے بغیر ممکن نہیں۔
- "جاری رکھیں" ٹیب کھلے رہنے تک ہے۔ ری لوڈ کے بعد متن اور SRT/VTT محفوظ رہتے ہیں مگر پروسیسنگ دوبارہ شروع کرنے کے لیے فائل دوبارہ دینی ہوگی۔
- پہلی بار انٹرنیٹ لازمی؛ اس کے بعد لائبریری اور ماڈل کیش ہو جاتے ہیں اور ایپ آف لائن چلتی ہے۔

## رازداری
آڈیو کسی سرور کو نہیں جاتی؛ صرف لائبریری (jsDelivr) اور ماڈل (Hugging Face) ڈاؤن لوڈ ہوتے ہیں۔ ٹرانسکرپٹ صرف اسی براؤزر میں محفوظ ہوتا ہے؛ "متن حذف کریں" سے مٹ جاتا ہے۔

## ٹیسٹ
- `node tests/core.test.js` — منطق (ونڈو تقسیم، دوبارہ کوشش، resume، سب ٹائٹل ٹائمنگ): 11 ٹیسٹ۔
- `python3 tests/e2e.py` — حقیقی Chrome میں 41 چیک (اپ لوڈ، ڈی کوڈنگ، ڈاؤن لوڈز، خرابی/ریکوری، آف لائن SW)۔ **نوٹ:** ان میں Whisper ماڈل نقلی ہے (ٹیسٹ ماحول میں انٹرنیٹ نہ تھا)، اصل ٹرانسکرپشن کی درستگی اور رفتار ان سے ثابت نہیں ہوتی۔ ffmpeg، playwright، python-docx اور LibreOffice درکار ہیں۔
